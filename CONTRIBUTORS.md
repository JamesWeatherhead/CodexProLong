## Git attribution

GitHub's native Contributors widget resolves commit email addresses to GitHub
accounts. James has a GitHub account; this Codex agent does not. We will not
spoof an OpenAI organization, GitHub App, bot, or human account merely to gain
an avatar in that widget.

Instead:

- human-owned commits use James's verified GitHub noreply identity;
- AI-authored commits use `Codex <codex-agent@openai.invalid>` with James as
  the authenticated committer;
- this file, the README collaborator cards, provenance records, verifier
  receipts, and append-only journal make the division of work explicit;
- "Codex" describes the coding-agent interface, not a claim that the agent is
  a legal person, repository owner, or independent GitHub user.

This gives public credit without manufacturing an account or misrepresenting
who controls the repository.
