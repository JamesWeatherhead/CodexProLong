# Visual assets

The four files in this directory were prepared for the CodexProLong public
release:

- `prolong-memory-codex.webp` — identity illustration used in the README;
- `codexprolong-system-loop.webp` — high-level architecture illustration;
- `live-flat-polynomials-research-trace-8K.png` — timestamped 8K trace of an
  active exact research lane; and
- `social-preview-1200x630.jpg` — repository social preview.

The three illustrated assets are AI-assisted editorial art made for this project;
no official logos are used. None of the assets is official artwork from or an
endorsement by OpenAI, EinsteinArena, PRO-LONG, Exa, or Paperclip. Source-sized
working files and generation intermediates are not included in the current
release tree.
