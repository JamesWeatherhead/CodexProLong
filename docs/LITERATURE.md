# Literature map

Paperclip is the campaign's full-text literature layer. Each benchmark lane is
being mapped to primary papers or authoritative datasets, with supporting text
read directly and citations pinned to Paperclip line ranges before claims are
posted.

The current public packet is being rebuilt because Paperclip's direct arXiv
source returned empty results for known records. As a controlled fallback, the
relevant arXiv PDFs are fetched into a private Paperclip clipboard and indexed
there; citations will appear here only after full-text line verification.

> [!NOTE]
> This file intentionally contains no speculative references. A DOI/title is
> not treated as evidence until the supporting passage has been read.
