# License and provenance boundary

Surviving metadata identified the deleted repository as Apache-2.0 on three
independent surfaces: its cached README badge, the dated
`awesome-agent-evolution` repository snapshot, and the ecosyste.ms repository
record.

That metadata does not substitute for complete redistribution compliance. The
original upstream `LICENSE` and any `NOTICE` bytes were not recovered, and a
cached rendering is not proof of the original Git blob. Consequently this
publication packet excludes all recovered third-party source, README and paper
text, verifier text, coordinate tables, generated candidates, archive payloads,
and registry responses. Their hashes may appear solely as evidence identifiers.

No claim is made that the excluded material is relicensed. Republishing any of
it requires obtaining the canonical Apache License 2.0 text, preserving
upstream copyright and attribution notices, checking for an upstream `NOTICE`,
and separately reviewing non-code content and generated numerical artifacts.
