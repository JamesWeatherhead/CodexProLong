# Provenance and publication limits

The Python and Markdown files in this directory were authored for this campaign
lane. They implement graph operations and numerical optimization from first
principles; no third-party source code was copied or vendored.

The literature record contains bibliographic facts, hashes, line locators, and
original paraphrases. It contains no paper text or figures. Exa response bodies
and snippets were not retained. The Cambridge N=282 XYZ was inspected by GET in
memory and hashed, but its bytes were not retained because no redistribution
license was established.

The frozen Arena snapshot, verifier, research corpus, and incumbent-derived
coordinate candidate are not publication inputs. Their hashes are retained for
reproducibility, while the files themselves are excluded.

The original packet code and prose are released under the packet-local MIT
`LICENSE`. This grant does not extend to excluded Arena payloads, source
papers, Exa/Paperclip response bodies, or Cambridge coordinate bytes.

Dependencies are imported at runtime and are not vendored: Python, NumPy,
SciPy, and NetworkX. Their own licenses apply to installations obtained by the
reproducer.
